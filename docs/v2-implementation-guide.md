# Bunny Bunny v2：世界与聊天使用说明

本页说明 `bunny-v2-original` 上已经接通的玩法。涉及 CHAR/NPC 自主写作的功能需要先在「模型与 API」配置可用的文本模型；无模型时已有聊天、日程、世界事件和手动编辑仍可查看。

## 从哪里开始

1. 在「联系人 → 世界观编辑」新增世界，设置名称与时区，再在该世界放入 CHAR 和 NPC。删除世界时，相关群聊会归档；角色资料不会因此丢失。
2. 在「聊天 → ＋ / 创建群聊」选择同世界的至少两位角色。群内可以设置公告、群昵称、免打扰、邀请或移出成员、发送 @ 消息与拼手气红包。群聊和好友是两种关系：NPC 可以在群里说话，但只有当前 USER 账号与 NPC 成为好友后，他才可能私聊。
3. 发群消息后，模型按在场成员、各自日程和近几条消息生成接话。群中实际发言会进入在场角色各自的记忆；世界恢复前台时可补算有限的角色相遇与群内消息。群聊里的某件事可能在几分钟后成为好友发来的私聊，私聊会引用群中具体内容。
4. 在 CHAR 聊天页发送若干轮消息。心声活动首次约在第六轮后出现，此后至少相隔九轮、二十分钟；同话题还会延后。未读气泡在头像旁出现，点开查看。也可用输入框「＋ → 心声」手动查看。心声只属于当前世界、账号和对话，不会发给 CHAR。
5. 在双方文字消息的长按菜单选「回声」，或者在「＋ → 回声」预选下一条。气泡与文字会分别铺开运动。聊天设置中的气泡 CSS、文字颜色、大小与圆角会反映到回声副本；系统启用减少动态效果时不播放。
6. 在「聊天设置 → CHAR 的日记」看按角色当地日期保存的日记。角色会在当日晚间写；也可在日记页检查新一页。日记参考当天的日程、对话和可知世界事件。阅读需要关系进展达到门槛，未解锁时仅显示日期。
7. 在「聊天设置 → 记忆档案」点开核心记忆、状态、分层、类别或单条卡片。单条可看原消息来源，纠正、置顶、隐藏或删除；检索会排除隐藏、争议和删除内容。不同世界与 USER 账号的记忆分别归档，NPC 同样有日程、关系边和记忆。
8. 在「联系人 → 关系网」按世界查看 CHAR 与 NPC 的关系。长按关系标签可看亲近度、信任与近期变化，也能手动记录一件增进或损害关系的事。

## X：资料与动态

1. 从桌面打开 X，右上角「⚙」进入 X 设置。先在手机的「模型与 API」配置主模型，或者在 X 设置中选择专用 API、填写接口地址、Key 和模型并测试。保存后点「一键刷新主页」；默认每次请求 5 条主贴和 9 条评论，条数可调。
2. 同一设置页可选择 X 世界书、新建或编辑条目，填写世界观介绍、发帖规则与扩展文风；这些内容只用于 X 的生成。自动刷新可设为进入 X、按时间间隔，或 USER 发帖达到指定次数。新动态保留已有帖子。
3. 在「网络 NPC 头像池」从相册批量选择图片，或逐行粘贴图床直链。生成的新网友依次使用头像；删除池中图片不会删除其已发布的内容。
4. 在「管理网络身份」选择 USER、CHAR、NPC 或网友，设置昵称、用户名、简介、签名、职业、所在地、网站、头像、封面、名气、认证与现实身份关联。自己的资料也可从「我 → 编辑个人资料」进入。现实身份未公开时，生成内容不会把该关联当作公开事实。
5. USER 可发布文字和图片、回复、点赞、转发、收藏与搜索。发布后，开启「角色回应 USER 新帖」会让同世界的角色按具体内容选择是否评论或点赞。X 私信可主动发送，并由模型生成对方的回复；也可点「让对方回复」重试。CHAR 看到值得分享的贴文时，有机会在已有聊天中自然提起；NPC 需要先和 USER 成为好友。

- X 内容与私信按世界和 USER 账号隔离。模型输出若引用其他世界、无效作者或不存在的贴文，会在写入前被丢弃。模型生成需要可用 API；没有 API 时已有本地贴文及手动互动仍可使用。

## 运行规则

- 世界事件先记录参与者与见证者，角色只能使用亲历、被告知或公开的事实。关系数值每个事件最多变化四点，重复事件不会重复结算。离线补算以六小时为片段，最多补算近 72 小时。
- 群聊发言人必须是仍在群内、同世界且当前可回复的 CHAR/NPC；模型输出名单外 ID 会被丢弃。群红包先核对成员和余额，再将同一消息 ID 写入钱包账本与群消息。
- 记忆摘要必须带真实消息来源 ID。它会检查原文证据，限制没有明确依据的承诺；主观印象不应被写成 USER 的决定。日记和心声可以带人物主观色彩，但不自动变成 USER 的事实。
- 本项目当前以浏览器本地数据为主。规格书里更完整的离线投递状态机、数据库迁移、冲突约定审批、世界事件编辑审计和跨设备同步仍属于后续工程范围；目前的规则与 UI 不应被理解为这些条款已全部实现。
